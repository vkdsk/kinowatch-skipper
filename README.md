## 📌 О проекте

**Kino.watch Skipper** — это юзерскрипт для браузера, который делает просмотр сериалов на платформе *kino.watch* комфортнее. Он заменяет ручную перемотку на автоматический пропуск заставок/титров и позволяет сообществу совместными усилиями размечать таймкоды для новых серий.

---

## ✨ Основные возможности

- ⏭️ **Пропуск заставки/титров:** При начале заставки появляется кнопка с пропуском заставки.
- ⏲️ **Автопропуск с обратным отчетом:** При начале заставки появляется 7-секундный плавный таймер пропускa.
- ⚙️ **Настройка автопропуска:** При нажатии на кнопку настройки можно отключить и изменить таймер перемотки.
- 🛑 **Кнопка отмены:** Если вы не хотите пропускать заставку в конкретной серии — его можно отменить в один клик.
- 🎯 **Краудсорсинг меток (Opt-In):** Кнопка отправки заставки доступна только для пользователей, которые еще не отправляли сегмент заставки для пропуска.
- 🛡 **Умная валидация:** Защита от случайных кликов — скрипт и сервер отклоняют отрезки короче 10 секунд и длиннее 5 минут.
- 🎨 **Кастомный UI:** Всплывающие стилизованные уведомления (Toast) о принятых отметках и ошибках.

## 📥 Быстрая установка

1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** для вашего браузера.
2. Нажмите на ссылку ниже для автоматической установки скрипта:

<div align="center">

👉 **[Установить Kino.watch Skipper](https://kw.xlnt.ovh/kino-skipper.user.js)** 👈

</div>

3. Подтвердите установку во всплывающем окне Tampermonkey.
4. Откройте любой плеер на `kino.watch` и наслаждайтесь просмотром!

---

## 🛠 Как разметить заставку (для новых серий)

Если у серии еще нет сохраненной заставки и вы ее не размещали:

1. В плеере появится синяя кнопка **«Отменить заставку»**.
2. В момент начала заставки нажмите на кнопку — она станет красной и начнет фиксировать время.
3. В момент окончания заставки нажмите на нее повторно.
4. В появившемся окне подтвердите отправку. 
> *После консенсуса нескольких пользователей заставка станет автоматической для всех!*

## 🌐 Стек технологий

* **Client:** JavaScript (ES6+), Tampermonkey / UserScript API, GM_xmlhttpRequest, Custom CSS
* **Server:** PHP 8.x, PDO, MySQL/MariaDB

---

## 🤔 Какие данные собираются?

* **Ник:** шифруется на стороне пользователя и зашифрованный ник отправляется в нашу базу данных.
* **Временные метки:** метки заставки/титров, отправленные пользователем, без шифрования отправляются в нашу базу данных.
