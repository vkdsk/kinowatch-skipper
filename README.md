## 📌 О проекте

**Kino.watch Intro Skipper** — это юзерскрипт для браузера, который делает просмотр сериалов на платформе *kino.watch* комфортнее. Он заменяет ручную перемотку на автоматический пропуск заставок и позволяет сообществу совместными усилиями размечать таймкоды для новых серий.

---

## ✨ Основные возможности

- ⏱ **Автопропуск с обратным отчетом:** При начале заставки появляется 5-секундный плавный таймер пропускa.
- 🛑 **Кнопка отмены:** Если вы не хотите пропускать опенинг в конкретной серии — его можно отменить в один клик.
- 🎯 **Краудсорсинг меток (Opt-In):** Кнопка отправки заставки доступна только для пользователей, которые еще не голосовали для текущего эпизода.
- 🛡 **Умная валидация:** Защита от случайных кликов — скрипт и сервер отклоняют отрезки короче 2 секунд и длиннее 3 минут.
- 🎨 **Кастомный UI:** Всплывающие стилизованные уведомления (Toast) о принятых отметках и ошибках.

1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** для вашего браузера.
2. Нажмите на ссылку ниже для автоматической установки скрипта:

<div align="center">

3. Подтвердите установку во всплывающем окне Tampermonkey.
4. Откройте любой плеер на `kino.watch` и наслаждайтесь просмотром!

---

## 🛠 Как разметить заставку (для новых серий)

Если у серии еще нет сохраненной заставки и вы ее не размещали:

1. В плеере появится синяя кнопка **«Отменить заставку»**.
2. В момент начала опенинга нажмите на кнопку — она станет красной и начнет фиксировать время.
3. В момент окончания опенинга нажмите на нее повторно.
4. В появившемся окне подтвердите отправку. 
> *После консенсуса нескольких пользователей заставка станет автоматической для всех!*
